MOBI vs EPUB: Why the Transition Happened

In late 2022, Amazon notified Kindle users that the legacy proprietary MOBI (.mobi, .prc) format would no longer be supported by modern Kindle apps and the Send-to-Kindle system. EPUB is now the universal global standard for reflowable digital text.

Feature MOBI (Legacy) EPUB3 (Modern Standard)
Amazon Send-to-Kindle Support Deprecated Fully Supported
Modern CSS3 & Typography Limited / Broken Full Support
Font Scaling & Dynamic Hyphenation Poor Enhanced (Bookerly)
Cross-Platform Compatibility Kindle only Apple Books, Kobo, Android, Kindle

How the Client-Side Engine Operates

  • Binary Record Slicing: Reads the Palm Database format (PDB) header and parses the 78-byte MobiHeader.
  • PalmDOC Decompression: Unpacks compressed LZ77 chunks directly in memory without heap fragmentation.
  • HTML/CSS Normalization: Replaces obsolete Kindle 3 tags with valid HTML5 and responsive stylesheet standards.
  • EPUB3 Archiving: Assembles the Open Container Format (OCF), package document (.opf), and navigational document (.xhtml) into an uncompressed mimetype and Deflated ZIP.
